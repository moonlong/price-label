# 商品结算打印 App（价格便签）

面向日本客户销售饰品（非标品）的结算辅助工具：替代「计算器 + 手写便签」，在手机上快速算出每组总价并打印 50×50mm 便签（尺寸可在配置里改）。

## 运行环境
- 安卓手机 + Chrome/Edge（PWA），部署到 HTTPS 静态托管（如 GitHub Pages）。
- 打印走 Web Bluetooth（驰腾 CT221B，BLE，TSPL + 位图，已联调可用）。

## 本地查看与测试

```bash
# 启动本地静态服务器（零依赖）
node server.mjs
# 浏览器打开 http://localhost:8080

# 运行单元测试 + 集成测试
node --test test/
```

> 提示：直接用 `file://` 打开会因 ES Module 的 CORS 限制而失败，请用上面的本地服务器。

## 客户 JSON 配置格式

```json
{
  "version": 1,
  "label": { "widthMm": 50, "heightMm": 50 },
  "print": { "offsetXmm": -1.5, "offsetYmm": 0 },
  "customers": [
    { "no": 1, "name": "佐藤" },
    { "no": 2, "name": "鈴木" }
  ]
}
```

- 客户 = **编号 `no`（唯一）+ 名字 `name` + 星标 `favorite`**；**默认客户名单为空**（干净版），使用时通过「客户管理 / 导入导出」导入你自己的名单，避免误用/覆盖。
- 导入规则：**已有编号原样保留**；缺失编号的客户按「最大编号 + 1」自动追加；编号重复报错。
- `label.widthMm/heightMm`：标签纸尺寸，**换纸只改这里**（默认 **50×50**；例如换回 40×30 就改成 `"widthMm": 40, "heightMm": 30`），重新导入即生效，无需改代码。
- `print.offsetXmm`：整体水平偏移，**负=左移、正=右移**（当前默认 -1.5mm 略左移）；`print.offsetYmm`：垂直偏移。
- 客户名单与标签尺寸都在此文件；App 内「客户管理 / 导入导出」可**导出 → 改 → 重新导入**（整体替换）。
- 顶部搜索框：**输入编号（数字）按编号前缀匹配，输入文字按名字匹配**；默认不折叠、常显。
- 结算历史：每次「打印合计」后自动记录一条；「结算历史」里可导出 CSV（`date, customer, total`）或点某行复制「客户名 总价」。

## 操作流程
1. 选客户 + 枚目 → 键盘输入 →「计入」累加（可「撤销」）。
2. 「本组结束」：
   - 条目数 ≤3 → 直接进打印预览。
   - 条目数 >3 → 自动进入**双录核对**：提示"已记录，请再次录入核对"，再录一遍；一致（✓）才进预览，不一致（✗）显示差额并重录，直到最近两次一致。
3. 打印预览：默认打印本组；若这是**最后一组**，打开「最后一组（附合计）」开关，预览多出「合計」行，打印后本单结束。
4. 汇总区常驻「本单合计」，并显示各枚目状态（未打印 / 已打印 / 需重打 / 核对中）。

## 计算规则（准确性）
- 仅整数日元；运算符 `+ − × ÷`，**标准优先级**（先乘除后加减），无括号。
- 十进制精确计算，**除法四舍五入到整数**；非法输入（空、`5+`、除 0 等）提示且不累加。
- 结束本组/合计前，输入框未累加的内容会**自动先累加**（防漏加）。
- 撤销 = 弹出上一条并重算小计；合计口径 = 所有枚目当前金额之和。
- 双录核对只比对**小计**（两次可故意用不同录入方式），比对由机器完成，不靠人工判断。
